Tải File Excel Mẫu (.xlsx)
Hướng dẫn cấu hình File Excel:
  • Cột A: Nội dung câu hỏi (bắt buộc)
  • Cột B: Loại câu hỏi (trắc nghiệm, chọn nhiều, điền khuyết)
  • Cột C: Mức độ (dễ, trung bình, khó)
  • Cột D -> K: Các lựa chọn đáp án từ A -> H
  • Cột L: Đáp án đúng (Ví dụ: A hoặc A,B đối với chọn nhiều)
  • Dòng đầu tiên là tiêu đề cột và sẽ tự động được hệ thống bỏ qua.
